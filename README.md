# HiCar 安卓接收端

在安卓设备上运行的实验性 HiCar 接收端。华为手机使用系统自带的 HUAWEI HiCar，接收端安装本项目 APK。

本项目为社区实验，非华为官方产品，未获华为 HiCar 官方认证。HiCar 等名称和商标归其权利人所有。

当前版本：**0.11.1 Preview**（工作区为 0.11.2 开发中）。已具备视频、音频播放、触控和返回操作。0.11.2 起默认启用「无感回连」：已配对手机断线后由车机关闭 FDEE 广播，主动拨通 FE35 完成 Nearby 协商、索取业务端口并连 FE36 免密认证。该路径已于 2026-11-10 在 Android 9 车机 + 华为手机上完成真机验证（含冷启动回归，约 21 秒出画、持续投屏无异常）；首次配对仍需要手机侧确认一次并输入连接码。

## 使用要求

- 接收端：安卓设备，具备蓝牙、BLE 广播及所需的 Wi-Fi 热点能力。最低支持 Android 5.1（API 22）、目标 API 35；
  Wi-Fi P2P 在 API 29+ 用 Builder 指定 5745 MHz（信道 149），API 22-28 用反射固定信道，
  Android 9 / API 28 车机已完成端到端无线连接验证。
- APK 包含 `armeabi-v7a` 和 `arm64-v8a`；不含 x86/x86_64 原生库。
- 发送端：支持原生 HUAWEI HiCar 的华为手机。当前已有 HarmonyOS 4 发送端实测；**不能据此承诺 HarmonyOS 5/6 兼容**。
- 发送端不安装辅助 APK，不需要 root。普通使用不依赖电脑或通过 USB 提供网络地址。
- 热点配置和运行地址读取包含系统接口兼容路径，可能受系统版本和厂商限制。不是所有安卓设备都能运行。

## 首次使用

1. 将同一 APK 安装到接收端，开启蓝牙和 WLAN。
2. 首次先在两台设备的系统蓝牙设置完成普通配对。该步骤在部分测试设备上是连接成功所需的操作。
3. 接收端点击“开始连接”，允许附近设备权限及系统蓝牙可发现请求。
4. 华为出现 HiCar 提示后按提示连接；首次输入接收端显示的六位连接码。连接码属于本机私有数据，请勿上传截图或日志中的敏感信息。
5. 出画面后顶部连接信息默认隐藏，可通过“菜单 → 显示连接信息”展开。
6. 结束时点击“停止连接”。

首次权限与配对完成后，可按应用中的提示配置本机蓝牙身份，以进行可信重连实验。地址只在接收端本地填写，不需要发送给维护者。

已配对手机再次启动接收时，应用不再请求系统蓝牙可发现，而是由车机主动回连，避免触发手机侧「靠近发现」确认弹窗。

## 开机自动接收

首页开启“开机自动接收”，并按系统需要允许自启动、后台运行和通知。可先点“试运行自动接收”验证接收流程。

- 自动启动时先等待蓝牙就绪，不静默开启蓝牙。
- 后台不强制弹出接收画面；点击服务通知或从应用返回接收画面。
- 自动启动模式不启用麦克风，语音实验需通过前台手动重新连接启用。
- 实测中出现过：开机服务和广播已运行，但手机不连接；重新进行两端普通蓝牙配对后又能连接，随后重启仍失败。**原因仍未确定，反复删除配对不是正式解决方案。**
- 车机完全开机、ACC 休眠唤醒与普通手机解锁后的开机广播不是同一场景，需要分别验证。

## 兼容性记录

| 接收端 | 发送端 | 已确认的范围 |
| --- | --- | --- |
| Android 17，64 位测试设备 | Mate 40 Pro / HarmonyOS 4 | 画面、声音、触控、部分可信重连、接收端锁屏恢复、麦克风及界面功能 |
| Find X3 Pro / Android 14，64 位进程 | Mate 40 Pro / HarmonyOS 4 | 画面、声音、触控；发送端锁屏恢复；后台接收试运行；开机服务启动 |
| Android 9 / API 28 车机 | 华为手机（EMUI 14.2） | 无感回连、5 GHz 信道 149、H.264 出画、DMSDP 心跳持续稳定（2026-11-10 冷启动回归）|

这些结果来自具体设备和操作，不等于同版本全部机型通过。当前尚未完成 32 位车机、Android 15 车机、纯鸿蒙发送端及长时间稳定性验证。仅在停车状态测试，不将实验版用于依赖持续可靠连接的驾驶场景。
