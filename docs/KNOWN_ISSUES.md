# 已知问题

## 重启后无法回连

0.11.0 已观察到接收服务、热点、蓝牙监听和发现广播启动成功，但手机未建立 HiCar 连接。手机的“自动连接”开启也不保证能连接。普通蓝牙重新配对曾恢复连接，但再次重启仍失败，原因未确定。

反馈时请说明：是否重启过接收端、普通配对是否成功、是否出现 HiCar 提示，以及接收页的状态。不要清除所有蓝牙或 HiCar 数据来替代诊断。

## 热点接口与权限

不同厂商会隐藏热点地址或限制接口。Android 13–15 使用本地热点兼容接口，系统启动回调必须保留本轮配置地址，并返回可用频道；Android 16 及以上走相应创建入口。不能取得可用参数时会停止，不发送占位地址。接口调用结果不等于设备在无线侧采用该地址，仍需真实连接验证。

## 麦克风

语音实验默认关闭，仅在手机发起语音请求时采集。其他通话应用可能影响录音；出现识别问题时先结束接收端的其他通话，再做对照测试。开机自动接收不启动麦克风服务。

## 验证边界

编译成功、APK 安装成功、蓝牙接口注册、认证成功、解码器初始化都不分别等于完整可用。视频需以实际画面、声音需以实际听音、输入需以界面响应确认。

32 位原生库已构建，但尚无 32 位运行实测。车机和 HarmonyOS 5/6 发送端的兼容性待测试。
